## 🔬 Currently building

**[Resham Mitra](https://github.com/VarshiniRgithubio/resham-mitra)**: an uncertainty-aware Kannada AI assistant for sericulture (silk) farmers in Karnataka.
- Answers farmer questions in Kannada or English using official sericulture manuals (RAG)
- **Refuses when unsure** and points the farmer to a sericulture officer, instead of guessing
- Research focus: *when should a low-resource-language AI assistant stay silent?*
- Stack: FastAPI, Qdrant, MongoDB, BGE-M3 embeddings, Gemma 3 (runs offline), Next.js
